mend is one command-line tool that applies AI-written edits to a tree of text files. It reads all four formats models write — unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, and text-editor tool calls as JSON — finds the lines each edit names even when their whitespace or indentation drifted, and changes every file or none.

## Run it

```sh
node main.ts [options] [PATCH]
```
